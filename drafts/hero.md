# Hero Image Prompt Guide

Use this guide to create hero image prompt sheets for Musinique drafts.

## Output File Rule

Store prompt sheets in:

```text
musinique/images/
```

Filename:

```text
<draft-base-name>-prompts.md
```

## Standing Rule: Character Mandate

Every prompt must include a central character.

Good Musinique protagonists:

- a child singing beside an adult who is teaching the gesture
- a musician facing a machine that can imitate the sound but not the occasion
- a curator standing in front of a wall of identical playlist doors
- a songwriter holding a lyric sheet while synthetic voices circle the room
- a listener with headphones watching a platform turn attention into numbers
- a choir figure whose shadow is a waveform

Avoid:

- empty album-cover abstractions
- generic robots with headphones
- dashboards as the whole image
- visible text or readable lyrics
- glossy streaming-app mockups

## Visual Style

- musical, human, slightly uncanny
- warm stage light or intimate classroom light
- visible human posture and intention
- analog instruments plus subtle digital traces
- no visible text
- no logos

## Prompt Pattern

Each prompt should name:

1. central character
2. musical act
3. AI/platform tension
4. setting
5. emotional register
6. no visible text

Example:

```text
A songwriter sits at a wooden piano while a translucent machine choir copies her melody from the shadows, the human figure holding still in concentration, warm stage light, subtle waveform shapes in the air, intimate and philosophical mood, no visible text, no logos, no streaming interface.
```

## Research Addendum (2026-06-03)

**Research date:** 2026-06-03

**Topic tags:** songwriting

**Research notes:**
- For songwriting drafts, make the craft layer explicit: lyric, melody, harmony, rhythm, phrasing, rhyme placement, section contrast, and title placement do different jobs in the listener memory system.
- A good revision move is to identify the song seed. Does the draft begin from a lyric image, melodic contour, rhythmic feel, harmonic movement, story premise, or production texture?
- When the piece is about children, teaching, or folk material, emphasize repeatability and participatory memory: repetition, call-and-response, rhyme, and predictable variation are features, not simplifications.
