# Muse's Musinique films

Every pre-render film package Muse has authored for **independent music artists** on how to effectively use AI — making music, promoting music, and running the music business. Click a film's **render prompt** to open its `CLAUDE-CODE-RENDER.md` — paste that into Claude Code on the Mac to generate narration and render. Each film folder also carries `beat_sheet.json`, `scenes.py`, `ACTS.md`, `SHOTLIST.md`, `FACTCHECK.md`, and QC reports.
