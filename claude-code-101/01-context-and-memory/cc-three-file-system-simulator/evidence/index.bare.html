Bubble Sort

Walk through the list from left to right. Compare each pair of neighbors. If they're out of order, swap them. Do that whole pass again and again until you make it all the way across without swapping anything.

The biggest number "bubbles" to the right end on each pass, which is why the right side turns green first.
