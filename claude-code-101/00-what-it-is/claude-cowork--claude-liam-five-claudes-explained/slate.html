B03 · ILLUSTRATION · 16–27s

Chat
In plain English
You type a prompt, Claude replies. Like a chatbot.
How to set up
Gmail account (free) → claude.ai
Biggest mistake
Using it for everything. It forgets context between sessions.
Non-technical
A back-and-forth conversation. Every new chat starts fresh.

Rebuild — ProductCard · Code
Code
In plain English
Describe what you want built. Claude writes all the code, creates files, runs it.
How to set up
Code tab → Chat → Cowork. $10/month (verify current pricing).
Biggest mistake
Not giving Claude the full picture — it explores files instead of builds.
Non-technical
A building contractor for digital things.
motion: drawon · component: ProductCard
B05 · ILLUSTRATION · 38–48s
Rebuild — ProductCard · Projects
Projects
In plain English
A saved workspace. Claude always knows your brand, files, context — no re-explaining.
How to set up
Sidebar → Projects → New project → add files.
Biggest mistake
Treating it like a folder. It's not a folder — it's a trained assistant.
Non-technical
A new employee who already read the company handbook.
motion: drawon · component: ProductCard
B06 · ILLUSTRATION · 48–58s
Rebuild — ProductCard · Skills
Skills
In plain English
An instruction manual for one thing, built in plain text, triggered by /slash command.
How to set up
Write in plain text (Word, Notion, Excel). Upload to Claude. Share with your team.
Biggest mistake
One skill trying to do too many things. One skill = one job.
Non-technical
A recipe card. Followed the same way every time. Never pollutes other chats.
motion: drawon · component: ProductCard
B07 · ILLUSTRATION · 58–68s
Rebuild — ProductCard · Cowork
Cowork
In plain English
Organizes your files, browses the web, runs your computer, handles research and analysis.
How to set up
Left sidebar → Projects.
Biggest mistake
Dumping all your files in before starting — Claude reads everything before every task.
Non-technical
A chief of staff who can also use your computer.
