Who it's for

Anyone who writes code (or writing, or config, or anything text-shaped) and wants to stop being afraid of the command line. No prior Git experience assumed — we start from git init.

What you'll leave with

  • A working mental model of commits, branches, and remotes
  • Confidence to clone, commit, push, and pull
  • The three commands that get you unstuck when things go sideways
  • A real repo on GitHub, made by you, during the session

Rough agenda

  • 10:00 — What Git actually is (and isn't)
  • 10:30 — Your first repo, commit by commit
  • 11:15 — Branches, merges, and the undo button
  • 12:00 — GitHub: pushing, pulling, pull requests
  • 12:45 — Open Q&A
