What is this & who is it for?

It's a warm, 5-hour, no-jargon intro to Git — the thing your friend keeps saying you should learn. If you've ever emailed yourself a folder called final_final_v2, this one's for you.

01 · SNAPSHOT

Think in commits, not files

We'll draw it. On paper. With markers. Then in the terminal, so it clicks twice.

02 · BRANCH

Try things without fear

Branches are cheap. Mistakes are cheaper. We'll practice both, on purpose.

03 · PUSH

Your first repo on GitHub

By the afternoon, your project has a home. With a README. That you wrote.

"I came in convinced Git wasn't for me. I left with three repos and I've been pushing to them every week since." — Priya, spring cohort
