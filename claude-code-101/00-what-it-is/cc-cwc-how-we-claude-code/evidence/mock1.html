What you'll walk out knowing

By the end of the day you'll have a working mental model of Git — not just a list of commands you copy-pasted once.

01

The commit as a snapshot

Why Git thinks in snapshots, not diffs — and why that changes how you work.

02

Branch, merge, rebase

When each is the right tool, plus how to get out of the ones you regret.

03

Remotes & GitHub

Push, pull, PRs, and the etiquette of collaborating without stepping on toes.

04

Recovering from mistakes

reflog, reset, revert — the safety net that lets you experiment.

05

A workflow you can keep

A simple branching model that scales from solo projects to small teams.

06

Your own repo, pushed

Leave with a real project on GitHub, README and all.

Common questions

If yours isn't here, email hi@northsidecodecoop.org.

Do I need to know how to code?

Not really — if you can save a text file and open a terminal, you're set.

What laptop should I bring?

Mac, Windows, or Linux — all work. We'll help you install Git if you haven't.

Is it recorded?

Yes. Registered attendees get the recording within a week.
